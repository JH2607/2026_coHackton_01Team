# 2026 해커톤 프로젝트 - AI 맞춤형 로컬 여행 플래너

대한민국 로컬(성수, 홍대 등) 장소를 기반으로 사용자의 취향과 상황에 맞는 최적의 여행 코스를 추천하고, AI 챗봇 및 카카오맵 연동을 제공하는 스마트 여행 플랫폼입니다.

---

## 🛠️ 주요 기능 (Key Features)
1. **AI 맞춤형 코스 추천 (`ai_service.py`)**: 사용자 조건(지역, 예산, 시간, 동행 유형)에 따른 최적의 여행 코스 생성.
2. **AI 툴 호출 및 키워드 확장 (`chat_recommend`)**: 사용자의 자연어 질문 의도를 분석하여 검색 키워드를 유연하게 확장/축소하고, DB 검색 툴과 연동하여 검증된 장소(`place_id`)만 추천.
3. **DB 검색 및 카카오 API 연동 (`db_tools.py`, `kakao_service.py`)**: 로컬 데이터베이스와 카카오맵 서비스를 결합한 정확한 위치 및 상세 정보 탐색.
4. **인터랙티브 UI (`ui.py`, `chat_view.py`)**: Streamlit 기반의 직관적인 채팅 화면, 장소 카드, 지도 시각화 및 찜하기(즐겨찾기) 기능 제공.

---

## 📂 프로젝트 구조 (Project Structure)
- `ui.py`: 프론트엔드 및 전체 화면 라우팅
- `chat_view.py`: AI 채팅 및 찜하기 UI 컴포넌트
- `ai_service.py`: LLM 연동 및 AI 추천·채팅 로직 처리
- `db_tools.py`: DB 검색 및 툴 호출 스키마 정의
- `kakao_service.py`: 카카오맵 위치 정보 검색 및 검증
- `data/`: 장소 정보가 담긴 CSV 데이터셋
